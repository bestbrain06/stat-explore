Activity 01

Finding the Range

Find the range of the following data set:

12, 15, 18, 20, 25
Range = Highest value - Lowest value

Worked Solution

Highest value = 25

Lowest value = 12

Range = 25 - 12

Range = 13

Activity 02

Comparing Data Spread

Which class shows more consistent performance?

Class A

68, 69, 70, 71, 72

Class B

40, 60, 70, 80, 100

A smaller spread means the values are closer together.

Worked Solution

Class A has scores that are closer together, meaning it has less variation.

Answer: Class A

Activity 03

Finding Interquartile Range

Calculate the interquartile range of:

5, 8, 10, 12, 15, 18, 20
IQR = Q3 - Q1

Worked Solution

Lower half:
5, 8, 10

Q1 = 8

Upper half:
15, 18, 20

Q3 = 18

IQR = 18 - 8

IQR = 10

Activity 04

Finding Quartiles

Find Q1 and Q3 for the following data:

4, 7, 9, 12, 15, 18, 21
Arrange the data first. Find the lower half and upper half separately.

Worked Solution

Ordered data:
4, 7, 9, 12, 15, 18, 21

Lower half:
4, 7, 9

Q1 = 7

Upper half:
15, 18, 21

Q3 = 18

Activity 05

Finding Range From Data

The temperatures recorded over five days were:

28, 30, 31, 34, 40

Calculate the range.

Subtract the smallest value from the largest value.

Worked Solution

Highest value = 40

Lowest value = 28

Range = 40 - 28

Range = 12

Activity 06

Calculating Interquartile Range

A data set has:

Q1 = 15     Q3 = 25

Find the interquartile range.

IQR = Q3 - Q1

Worked Solution

IQR = 25 - 15

IQR = 10

Activity 07

Understanding Variance

Which measure describes the average squared distance of values from the mean?

It is closely related to standard deviation.

Worked Solution

Variance measures the average squared deviation from the mean.

Answer: Variance

Activity 08

Calculating Variance

Find the variance of:

6, 8, 10
Find the mean first, then calculate squared deviations.

Worked Solution

Mean = 8

Deviations:
-2, 0, 2

Squared deviations:
4, 0, 4

Variance:
(4 + 0 + 4) ÷ 3

Variance = 2.67

Activity 09

Meaning of Standard Deviation

Which statement best describes standard deviation?

Worked Solution

Standard deviation measures how far values usually are from the mean.

Answer: Average distance of values from the mean

Activity 10

Selecting the Correct Measure

Which measure is most useful for describing how spread out values are around the mean?

Think about the measure that uses the mean as its reference point.

Worked Solution

Standard deviation measures the spread of values around the mean.

Answer: Standard Deviation
